# uka-regexp

`wchar_t` 専用の、C++ 製バックトラック型正規表現エンジンです。外部ライブラリも STL も使いません。
**`uka_regexp.h` と `uka_regexp.cpp` の 2 ファイルをプロジェクトに入れるだけ**で使えます。

- C++98 の範囲で書いてあり、Visual C++ 6.0 や古い GCC から、最近の g++ / clang / MSVC までビルドできます（例外を有効にしてください。VC6 では `/GX`）。
- 複雑なテンプレートは使っていません（内部の小さな配列テンプレートだけ）。
- 先読み・後読み（可変長可）・再帰・条件分岐・アトミック・所有量指定子・.NET のバランシンググループなどに対応しています。
- 再帰を使わずに照合するので、長い入力でも C スタックは溢れません。

## 使い方

```cpp
#include "uka_regexp.h"

try {
    CRegexpW re(L"(\\d+)-(\\d+)");            // 不正なパターンなら CRegexpException
    CRegexpContext ctx;                       // マッチ結果と作業領域。スレッドごとに用意する

    if (re.Match(L"tel 03-1234", ctx)) {
        int s = ctx.GetStart(1);              // グループ1の開始位置 (0 は全体)
        int e = ctx.GetEnd(1);                // 終了位置（この位置は含まない）
        bool m = ctx.IsMatched(2);            // グループが参加したか
    }

    CRegexpString out;                        // Replace の出力用の簡易文字列
    int n = re.Replace(L"03-1234", L"$2-$1", out);   // out.c_str() == L"1234-03", n == 1
}
catch (CRegexpException& ex) {
    // ex.GetCode()      ERR_SYNTAX / ERR_STEP_LIMIT / ERR_NOT_COMPILED / ERR_MEMORY
    // ex.GetPosition()  ERR_SYNTAX のときパターン中の位置
    // ex.what()         英語のメッセージ
}
```

### フラグ

コンパイル時に第 2 引数で指定します（`CRegexpW re(L"abc", CRegexpW::IGNORECASE | CRegexpW::MULTILINE)`）。
パターンの中からも切り替えられます。

| フラグ | パターン内 | 意味 |
|---|---|---|
| `IGNORECASE` | `(?i)` | 大文字と小文字を区別しない |
| `MULTILINE`  | `(?m)` | `^` `$` を行頭・行末に一致させる |
| `SINGLELINE` | `(?s)` | `.` を改行にも一致させる |
| `EXTENDED`   | `(?x)` | パターン中の空白を無視し、`#` から行末までをコメントにする（`[...]` の中は除く） |
| `GLOBAL`     | `(?g)` | `Match()` が前回の続きから探す／`Replace()` が全部置換する |

`(?i)` はその位置からグループの終わりまで有効です。`(?i:...)` は括弧の中だけ、`(?-i)` は解除です。`(?im-sx)` のようにまとめて書けます。
選択肢の途中で変えた設定は、同じグループの後続の選択肢にも続きます（`(a(?i)b|c)` の `c` も大文字小文字を区別しません）。
`(?g)` はどこに書いても、パターン全体を GLOBAL にします。

### 主な関数

| 関数 | 説明 |
|---|---|
| `CRegexpW(pattern, flags)` / `Compile(pattern, flags)` | コンパイル。失敗しても（`Compile` なら）以前のパターンは保たれる |
| `Match(str, ctx)` | NUL 終端の文字列から最初のマッチを探す |
| `Match(str, len, ctx, start = -1)` | 長さ指定（NUL を含められる）。`start >= 0` ならその位置から探す |
| `Replace(str, repl, out)` / `Replace(str, len, repl, out)` | 置換。`GLOBAL` なら全部、そうでなければ最初の 1 つ。置換数を返す |
| `GetGroupCount()` / `GetGroupNumber(name)` | グループ数（0 番を除く）／名前からの番号（無ければ -1） |
| `SetStepLimit(base, perChar)` | バックトラック上限を変える（下記） |
| `ctx.GetStart(g)` `GetEnd(g)` `IsMatched(g)` `GetGroupCount()` | 結果の取得。文字列そのものは位置から切り出す |
| `ctx.Reset()` | `GLOBAL` の走査位置を 0 に戻す |

- `Match` は文字列中のどこかで最初に一致する部分を探します（先頭固定ではありません）。全体一致にしたいときは `\A...\z` を使ってください。
- `GLOBAL` のとき `start` を省略した `Match()` は、同じ `ctx` での前回の一致の終わりから探し、`while (re.Match(s, ctx)) {...}` で全部の一致を順に取れます。空の一致が続いて止まらないことはありません。失敗すると位置は 0 に戻ります。
- **スレッド**: コンパイル済みの `CRegexpW` は複数スレッドから同時に使えます。`CRegexpContext` はスレッドごとに用意してください。
- **ステップ上限**: `(.*a){12}c` のようなパターンは入力によって指数時間かかるため、バックトラック回数に上限があります。既定は `1000000 + 256 × 入力の長さ` で、超えると `ERR_STEP_LIMIT` の例外が飛びます。`\w+@` を単語文字が何万文字も続く入力に当てるような二乗オーダーのパターンも打ち切られます。バックトラック用スタックにも入力長に比例した上限（`4M + 32 × 長さ` 個）があり、同じ例外になります。

## 対応している正規表現

### 文字

| 構文 | 意味 |
|---|---|
| `a` `1` `あ` など | その文字そのもの |
| `\.` `\*` `\\` など | 記号の前に `\` を付けると、その記号そのもの。知らない `\y` なども `y` そのもの |
| `\t` `\n` `\r` `\f` `\v` `\a` `\e` | タブ・LF・CR・改ページ・垂直タブ・ベル・エスケープ |
| `\xHH` | 16 進 2 桁（`\x41` は `A`） |
| `\uHHHH` | 16 進 4 桁（4 桁に満たないときは普通の `u`） |
| `\x{...}` `\u{...}` | 16 進。U+10000 以上も書ける（`\u{1F600}`）。U+10FFFF を超えるとエラー |
| `\0` `\012` `\cA` | 8 進（`\0` + 最大 2 桁）／制御文字 |
| `\Q...\E` | 間の文字列を記号も含めてそのまま扱う（`\Qa.b\E`）。`\E` が無ければ最後まで。直後の量指定子は最後の 1 文字にかかる |
| `\U...\E` `\L...\E` | 間の文字列を大文字・小文字に変換してから、そのまま扱う（Unicode の 1 対 1 変換） |

`\N` や `\R` は対応していません（それぞれ文字 `N` `R` の意味になります）。

### 文字クラス

| 構文 | 意味 |
|---|---|
| `.` | 改行（LF）以外の任意の 1 文字（`SINGLELINE` では改行にも一致） |
| `[abc]` `[a-z]` `[^abc]` | 集合・範囲・否定。`[]a]` `[^]a]` の先頭の `]`、先頭・末尾の `-` は普通の文字。`[z-a]` はエラー |
| `\d` `\D` | 数字 `0-9` / それ以外 |
| `\w` `\W` | 単語の文字 `A-Za-z0-9_` / それ以外 |
| `\s` `\S` | 空白（スペース・`\t\n\v\f\r`）/ それ以外 |
| `\h` `\H` | 横方向の空白 / それ以外。スペース・タブのほか NBSP・U+1680・U+2000〜200A・U+202F・U+205F・全角スペース U+3000 を含む |
| `[[:alpha:]]` | POSIX クラス（ASCII）: `alnum alpha ascii blank cntrl digit graph lower print punct space upper xdigit` と `word`。`[[:^alpha:]]` は否定 |

`\d` `\w` `\s` `\h` `\p{..}` は `[...]` の中でも使えます（`[\d_]` `[\p{Lu}\d]`）。クラスの中の `\b` はバックスペースです。`[a-\d]` のように範囲の端がクラスのときは、`-` は普通の文字になります。
`\d` `\w` `\s` `\b` は **ASCII だけ**が対象です（`\d` は全角数字に一致しません）。

### Unicode プロパティ

`\p{L}` `\pL` `\P{L}` `\p{^L}` の形で、`[...]` の中にも書けます。Unicode 15.1 のデータを内蔵しています。

| 名前 | 意味 |
|---|---|
| `L` `M` `N` `P` `S` `Z` `C` | 一般カテゴリの大分類 |
| `Lu` `Ll` `Lt` `Lm` `Lo` `Mn` `Mc` `Me` `Nd` `Nl` `No` `Pc` `Pd` `Ps` `Pe` `Pi` `Pf` `Po` `Sm` `Sc` `Sk` `So` `Zs` `Zl` `Zp` `Cc` `Cf` `Cs` `Co` `Cn` | 2 文字のカテゴリ名すべて |
| `L&` `LC` | `Lu` `Ll` `Lt` |
| `Any` `Assigned` `ASCII` | 任意の文字 / 割り当て済み / U+0000〜007F |
| `White_Space` `Space` | Unicode の空白（全角スペース・U+2028・U+0085 なども） |
| `Word` | 単語の文字（`L` `M` `Nd` `Nl` `Pc` と U+200C/200D） |
| `Xan` `Xwd` `Xsp` `Xps` | PCRE 互換: 文字と数字 / 文字・数字・`_` / 空白（`Z` と `\t\n\v\f\r`）/ 空白 |

スクリプト（`\p{Hiragana}`）やブロックには対応していません。知らない名前は、`\p{..}` ならどの文字にも一致せず、`\P{..}` ならすべての文字に一致します（エラーにはしません）。
`IGNORECASE` のとき `\p{Lu}` `\p{Ll}` `\p{Lt}` は、大文字・小文字・タイトルケースのどれにも一致します。

### 位置

| 構文 | 意味 |
|---|---|
| `^` `$` | 文字列の先頭 / 末尾。`MULTILINE` では行頭 / 行末（行の区切りは LF のみ。`$` は末尾の改行の**手前には一致しません**） |
| `\A` / `\z` | 文字列の先頭 / 末尾 |
| `\Z` | 文字列の末尾。末尾の改行の直前にも一致 |
| `\b` `\B` | 単語（ASCII）の境界 / 境界以外 |
| `\G` | 検索を始めた位置。`GLOBAL` なら前回の一致が終わった位置 |
| `\K` | 一致の開始位置をここにする。それより前は条件として調べるだけで、一致には含めない（`foo=\Kbar`） |

`^` `\b` などは、`start` を指定して途中から探したときも、文字列全体を基準に判断します。

### 量指定子

| 構文 | 意味 |
|---|---|
| `*` `+` `?` `{n}` `{n,}` `{n,m}` | 繰り返し（n, m は 65535 まで）。`{n,m}` で n > m はエラー |
| `*?` `+?` `??` `{n,m}?` | 最短一致 |
| `*+` `++` `?+` `{n,m}+` | 所有量指定子（繰り返した分を手放さない） |

量指定子として読めない `{`（`a{,3}` `a{` `a{1`）は普通の文字です。前に何も無い `*` `+` `?` も普通の文字になります。`a**` のように重ねて書くこともできます（32 個まで）。
空文字列にマッチする繰り返しは、1 周で何も進まなければそこで打ち切ります。

### グループと参照

| 構文 | 意味 |
|---|---|
| `(...)` | キャプチャするグループ（開き括弧の順に 1, 2, ...） |
| `(?:...)` | キャプチャしない |
| `(?<name>...)` `(?'name'...)` `(?P<name>...)` | 名前付き。名前は英数字・`_`・非 ASCII 文字。**同じ名前を複数回使うと同じグループ番号を共有します**（.NET と同じ） |
| `(?<2>...)` | 番号指定。以降の自動番号はその次から |
| `(?\|...\|...)` | ブランチリセット。選択肢ごとに同じ番号から振り直す |
| `(?>...)` | アトミックグループ |
| `\1` `\2` ... | 後方参照。`\10` 以上は、その数のグループがすでにあれば参照、無ければ 8 進文字。参加していないグループへの参照は失敗する。存在しないグループ（`\9` など）はエラー |
| `\k<name>` `\k'name'` `\k{name}` `(?P=name)` | 名前による後方参照（`\k<1>` のように番号も可） |
| `\g1` `\g{1}` `\g{-1}` `\g{name}` `\g<name>` `\g<1>` `\g'name'` | 番号・相対番号・名前による後方参照（`\g<..>` も**参照**であって呼び出しではない） |
| `(?#...)` | コメント |

`IGNORECASE` のとき後方参照も大文字小文字を無視して比べます。大文字小文字の無視は、ASCII に限らず Unicode の単純な case folding（`д`/`Д`、`σ`/`ς`/`Σ`、`K`/U+212A など）に従います。`ß` と `SS` のような複数文字への展開は扱いません。
繰り返しの中のグループは、最後に参加した周の値を保ちます（次の周で参加しなくても消えません。PCRE・.NET・Python と同じで、Perl・JavaScript とは違います）。

### 先読み・後読み・条件・再帰

| 構文 | 意味 |
|---|---|
| `(?=...)` `(?!...)` | 肯定先読み / 否定先読み |
| `(?<=...)` `(?<!...)` | 肯定後読み / 否定後読み。**中身は可変長でもよい**（`(?<=ab+)c`）。短い方から順に試すので、後読みの中のグループには最短の候補が入ります。上限の無い後読みは、文字ごとに先頭まで遡る可能性があるので重くなります |
| `(?(1)yes\|no)` `(?(name)yes\|no)` `(?(<name>)..)` `(?('name')..)` | グループが一致していれば yes、そうでなければ no（`\|no` は省略可） |
| `(?(?=...)yes\|no)` | 先読み・後読み（`?=` `?!` `?<=` `?<!`）の結果で分岐 |
| `(?(DEFINE)...)` | 中身は実行せず、`(?&name)` などで呼び出すための定義だけを置く |
| `(?R)` `(?0)` | パターン全体を再帰的に呼び出す |
| `(?1)` `(?-1)` `(?+1)` `(?R1)` `(?&name)` `(?P>name)` `(?R<name>)` `(?R'name')` | 指定したグループを呼び出す（`-1` は直前に開いたグループ、`+1` は次に開くグループ）。`^(\((?1)*\))$` は対応の取れた括弧に一致 |
| `(?<name-other>...)` `(?<-other>...)` | .NET 互換のバランシンググループ |

- 再帰・呼び出しは中でバックトラックできます。呼び出しから戻ると、呼び出しの中で変わったグループの値は呼び出し前に戻ります。同じ位置で自分自身を呼び出す無限の左再帰は、その経路が失敗するだけです。
- バランシンググループ: `(?<other>...)` が一致するたびに値が積まれ、`(?<-other>...)` が一致すると最後の値を 1 つ取り除きます（積まれていなければ失敗）。`(?<name-other>...)` は、取り除いた `other` の終わりからこのグループの開始までを `name` に記録します。取り除いた後は `(?(other)...)` で「まだ残っているか」を調べられます。例: `^(?:[^()]|(?<o>\()|(?<-o>\)))*(?(o)(?!))$` は対応の取れた括弧に一致します。
- 否定先読み・否定後読みの中で設定されたグループは、先読みを抜けると破棄されます。
- 条件の `(?(R)...)` には対応していません。

### 置換文字列（`Replace`）

| 構文 | 意味 |
|---|---|
| `$1` `$2` ... | その番号のグループが一致した文字列。`$10` はグループが 10 個以上あれば 10 番、無ければ `$1` の後ろに `0` |
| `${name}` `${1}` | 名前・番号で指定（番号の後ろに数字が続くときに便利） |
| `$&` / `$0` | 一致した文字列全体（`\K` を使えば `\K` 以降） |
| `` $` `` / `$'` | 一致した部分より前 / 後ろの、元の文字列 |
| `$+` | 一致したグループのうち番号が最大のもの |
| `$_` | 元の文字列全体 |
| `$$` | `$` という文字 |

存在しないグループや形式が合わない `$` は、そのままの文字として残ります。参加していないグループは空文字列になります。

### 不正なパターン

閉じていない `(` `[` や余分な `)`、存在しないグループへの参照、範囲の逆転（`[z-a]` `a{3,2}`）、未知の POSIX クラス名、未知のオプション文字（`(?z)`）、深すぎる入れ子（200 段）などは `ERR_SYNTAX` の例外になります。それ以外の曖昧な書き方は、できるだけ解釈してコンパイルします（上の表の各所を参照）。

## 制限（実装しなかったもの）

- 文字は `wchar_t` 1 個を 1 文字として扱います。`wchar_t` が 16 bit の環境（Windows）では、U+10000 以上の文字はサロゲート 2 つとして扱われます。`.` や `[^a]` は絵文字の半分に一致し、`\u{1F600}` のようにパターンに直接書いた場合はサロゲート 2 文字の並びになります（`[...]` の中では 2 つのうちどちらかに一致）。
- `\d` `\w` `\s` `\b` の Unicode 対応（UNICODE_MODE）、スクリプト・ブロックの `\p`、`\R` `\N`、`(?(R)..)`、バックトラッキング制御動詞 `(*VERB)` はありません。

## ビルドとテスト

```sh
make test            # 手書きケース (tests/cases_manual.txt) と API テスト (tests/test_api.cpp)
make compare-perl    # Perl 5.30 以降があれば、tests/cases_perl.txt を Perl の結果と比較
```

- `tests/run_cases.cpp` … タブ区切りのケースファイルを実行するランナー（`--verify` で期待値と比較）。
- `tests/cases_perl.txt` … Perl と比べるケース。仕様として違う 44 件は `tests/perl_known_diffs.txt` に記録してあり、増減すると `compare-perl` が知らせます。
- `tests/fuzz_gen.py` … Perl と比べるランダムパターンの生成器（`python3 tests/fuzz_gen.py SEED COUNT > file`、結果は `tests/perl_cases.pl` と `run_cases` で比べる）。
- Unicode のデータ（一般カテゴリ・大文字小文字変換）は `uka_regexp.cpp` の末尾に埋め込んであり、`make unicode-tables`（`tools/gen_unicode_tables.py`）で作り直せます。
